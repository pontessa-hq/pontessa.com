# pontessa.com

The public website of **Pontessa** — *AI adoption, piece by piece.*
Currently a one-page "coming soon" site (EN / PL / ES), served by **GitHub Pages** at https://pontessa.com.

## Structure
```
index.html              the page; all text lives in the T object near the bottom
favicon.ico / favicon.svg / apple-touch-icon.png
robots.txt
assets/                 logo, mark, background pattern, self-hosted Outfit font, social preview image
email/                  pontessa-email-icon.png, used by the email signature (keep this path)
```

## Notes
- No cookies, analytics or external requests (the font is self-hosted), so no cookie banner is needed.
- Language links: `/?lang=pl`, `/?lang=es`; otherwise the visitor's browser language is used.
- Brand rules: see the Pontessa Brand Identity v1.0 guide (colours ink navy `#1B2A41`, terracotta `#D9734E`; font Outfit).
- This repository is for the public website only. The Pontessa app will live in its own repository and be served at app.pontessa.com.
